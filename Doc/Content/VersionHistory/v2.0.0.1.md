Version 2.0.0.1 was released on July 7th, 2007.



## Changes in This Release

- Added a `ForceScriptRegistration` property to the web
`ImageMap` control.  This allows you to force registration of the postback script even if
it may not be used.  This is useful when the control appears in an Ajax panel and has no image areas when the
page is first loaded.

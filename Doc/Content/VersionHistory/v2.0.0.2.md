Version 2.0.0.2 was released on July 20th, 2007.



## Changes in This Release

- Removed code in the Windows Forms control that disposed of the image when the control is
disposed.  If using a project resource as the image, it should not be disposed of as the image can be used
elsewhere or in the same control at a later time.
